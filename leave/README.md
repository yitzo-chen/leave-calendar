# 員工休假月曆

公司內部休假總覽網頁：即時讀取 Google 試算表資料，顯示月曆檢視、可列印、可下載當月 CSV。
**填假本身還是在 Google 試算表操作**，這個網頁只負責把資料變好看、方便列印/下載。

## 檔案結構
- `index.html` — 頁面結構
- `style.css` — 樣式（含深色模式、列印樣式）
- `app.js` — 讀取試算表資料、月曆運算、列印/下載功能
- `config.js` — **唯一需要手動編輯的檔案**

## 設定步驟

1. 把「員工休假管理表.xlsx」上傳到 Google 雲端硬碟，用 Google 試算表開啟
2. 右上角「共用」→「一般存取權」改成「知道連結的使用者」→ 權限選「檢視者」以上即可
   （員工要能直接編輯的話選「編輯者」；這個網頁本身只讀取，不會寫入）
3. 複製網址列的試算表 ID：`https://docs.google.com/spreadsheets/d/【這一串】/edit`
4. 打開 `config.js`，把 ID 貼到 `SHEET_ID: ""` 中間
5. 確認 `ROSTER_SHEET_NAME` / `LOG_SHEET_NAME` 跟試算表分頁名稱一致（預設「員工名單」「請假紀錄」）

## 開放網頁直接填假（選用，資料一樣存在你的 Google 試算表）

不做這段的話，網頁一樣能瀏覽/列印/下載，只是「我要請假」按鈕會停用，填假仍要去開 Google 試算表填。

1. 打開你的 Google 試算表 →選單「擴充功能」→「Apps Script」
2. 把 `google-apps-script.gs` 的全部內容複製貼上，覆蓋掉預設的 `Code.gs`，按存檔（磁片圖示）
3. 右上角藍色「部署」→「新增部署作業」
4. 齒輪圖示選「網頁應用程式」，設定：
   - 執行身分：**我**（你自己的帳號）
   - 具有存取權的使用者：**所有人**（這樣員工才不用登入就能送出表單）
5. 按「部署」，第一次會跳出 Google 授權畫面——這是正常的（因為是你自己寫的私人腳本，
   Google 還沒幫你「驗證」，會顯示「Google 尚未驗證這個應用程式」的警告），
   流程是：選你的帳號 → 「進階」→「前往「員工休假管理表」(不安全)」→ 允許
6. 部署完成會給你一串網址，長得像 `https://script.google.com/macros/s/AKfycb.../exec`，複製起來
7. 貼到 `config.js` 的 `SCRIPT_URL`
8. 之後如果改了 `google-apps-script.gs` 的內容，要記得回到「部署」→「管理部署作業」→
   編輯（鉛筆圖示）→ 版本選「新版本」→ 部署，不然改動不會生效

## 幫「送出請假」加通關密碼（建議設定）

網頁本身（看月曆）不需要密碼，只有「我要請假」送出時會多要求一組密碼，擋掉
不知道密碼的陌生人亂送假單。**密碼值不會、也不能寫進這份程式碼**（寫進去的話
因為這個 repo 是公開的，等於直接公開密碼），必須自己到 Apps Script 的設定畫面
手動輸入：

1. 打開 Apps Script 編輯器（跟部署 `doPost` 同一個專案）
2. 左側齒輪圖示「專案設定」
3. 拉到最下面「指令碼屬性」→「新增指令碼屬性」
4. 屬性：`SUBMIT_PASSWORD`　值：你要設定的密碼（例如這次討論的密碼）
5. 儲存
6. 回到「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」→ 部署，讓新程式碼生效

沒有設定這個屬性的話，送出請假會維持原本不需密碼的行為（相容舊版）。之後想
換密碼，直接回「指令碼屬性」改值、不用改程式碼也不用重新部署。

**額外的兩層防護（只在有設密碼時才會啟用）：**
- **密碼錯誤鎖定**：短時間內密碼連續錯 5 次，會把「送出」整個鎖住 10 分鐘（因為
  Apps Script 拿不到呼叫者是誰，鎖的是全部人，擋的是自動化亂猜密碼）
- **稽核紀錄**：每次送出（成功／密碼錯誤／被鎖／重複送出被擋下）都會自動記一筆
  到試算表新分頁「送出紀錄」（時間、姓名、結果），分頁不存在時會自動建立，
  方便事後自己檢查有沒有可疑的密碼嘗試模式

## 假別欄位加下拉選單（建議跑一次）

手動在試算表「請假紀錄」分頁填假別時，只要打錯字（例如打成「特休」而不是
「全天」），這筆假期在網頁上會**完全不顯示、也不會有任何錯誤訊息**。加這道
下拉選單限制可以從源頭避免打錯字：

1. 貼完 `google-apps-script.gs` 的內容並存檔後，在 Apps Script 編輯器上方
   函式選單選 `setupLeaveTypeValidation`
2. 按「執行」（第一次執行一樣會跳出 Google 授權畫面，照畫面允許即可）
3. 完成後回試算表「請假紀錄」分頁的 D 欄（假別）就會變成下拉選單，只能選
   全天／上午半天／下午半天，不影響已經填好的舊資料
4. 只需要跑一次，之後新增列都會自動套用這個限制

## 發布到 GitHub Pages

```bash
git init
git add .
git commit -m "初版：員工休假月曆網頁"
git branch -M main
git remote add origin https://github.com/<your-account>/leave-calendar.git
git push -u origin main
```

推上去之後，到 GitHub 該 repo 的 Settings → Pages，Source 選 `main` branch、`/ (root)`，
存檔後幾分鐘網址就會是 `https://<your-account>.github.io/leave-calendar/`。

## 注意事項
- 這是**獨立的新 repo**，跟你其他私人 repo 完全無關，不會互相影響
- 這個 repo 一旦啟用 GitHub Pages 就是公開網頁，任何知道網址的人都能看到員工姓名與休假日期，
  請自行評估是否要放公司內部敏感資訊（例如請假事由備註），必要時可以把「備註」欄位排除在網頁顯示外
- 若試算表分頁被改名、或分享權限被改回「限制」，網頁會抓不到資料並顯示錯誤訊息、自動改顯示示範資料
- 部署成「所有人」都能用的 Apps Script 網址後，**任何知道這串網址的人都能送出請假申請**（不只是打開網頁的人），
  這跟你當初「完全開放、免登入」的設計是一致的，但如果之後想收緊，可以把 Apps Script 存取權改成
  「知道連結的使用者」或改寫程式加一組簡單通關密語
